# Maison Forfè — каталог в Telegram (новый дизайн)

## Что где лежит
- `public/index.html` — весь мини-апп: каталог, избранное, корзина, профиль.
- `public/uploads/homev-catalog-redesign/` — товары (`data.json`), фото, бейджи, иконки.
- `public/uploads/opt/` — сюда положить оптовые предложения:
  `maison-forfe-opt-ru.pdf` и `maison-forfe-opt-uz.pdf`. Кнопки в профиле появятся сами.
- `netlify/functions/order.mjs` — отправка заказов в группу. Токен бота хранится только в Netlify.
  Проверяет, что сертификат клиент использует один раз, и пополняет ленту «Недавно заказали».
- `netlify/functions/me.mjs` — статус сертификата клиента (одинаковый на всех устройствах).
- `netlify/functions/feed.mjs` — лента «Недавно заказали»: только набор и время, без имён.
- `netlify/functions/auction.mjs` — аукцион: цена лота, бронь на 5 минут, покупка, предложения цены, напоминания и админ-управление.
- `netlify/functions/auction-remind.mjs` — каждые 2 минуты рассылает напоминания за ~5 минут до старта лота.
- `netlify/lib/auction.mjs` — формула снижения цены (та же формула продублирована в `public/index.html`).
- `netlify/lib/tg.mjs` — общая проверка, что запрос пришёл из Telegram, и отправка сообщений ботом.
- `package.json` — подключает хранилище Netlify Blobs. Netlify устанавливает его сам при сборке.
- `netlify.toml` — настройки Netlify, менять не нужно.

## Статистика (только для владельца)
Профиль → «Статистика» (видно только ADMIN_IDS): заказы, выручка, средний чек и просмотры товаров
за сегодня / 7 / 30 дней, график по дням за 2 недели, «Чаще заказывают» и «Чаще смотрят».
- `netlify/functions/stats.mjs` — `/api/stats`: принимает просмотры и отдаёт сводку владельцу.
- `netlify/lib/stats.mjs` — по документу на день в Blobs: `stats/day/ГГГГ-ММ-ДД` (время Ташкента).
- Заказы считаются в `order.mjs` и при покупке на аукционе; тестовые («тест» в комментарии) — нет.
- Просмотры — сколько раз открыли карточку товара; без имён, свои просмотры владельца не считаются.
Данные начинают копиться с момента выкладки этой версии — прошлых заказов в статистике не будет.

## Если у клиента пропал интернет
Заказ не теряется: он сохраняется на телефоне (экран «Заказ сохранён», в профиле — «Ждёт отправки»)
и уходит сам, когда появляется связь, при возврате в приложение или при следующем открытии.
У каждого заказа свой номер-ключ (`oid`), поэтому `order.mjs` не отправит один заказ в группу дважды,
даже если ответ сервера потерялся по дороге. Ключи лежат в Blobs как `order/<oid>`.

## Несколько фото у товара (галерея)
В `data.json` у товара можно добавить поле `photos` — список дополнительных файлов из папки `photos/`:
```json
{"id": "item_0001", "photo": "Proja_Plus_31.jpg", "photos": ["Proja_Plus_31_2.jpg", "Proja_Plus_31_3.jpg"], ...}
```
Главным остаётся `photo`. Если фото больше одного, в карточке появляются листание, точки и счётчик,
а в каталоге — пометка «3 фото». Любое фото открывается на весь экран с увеличением.
Для чёткого увеличения лучше загружать фото шириной от 1400 px (сейчас многие около 700 px).

## Настройка в Netlify (один раз)
Site configuration → Environment variables:
- `BOT_TOKEN` — токен бота
- `ORDER_CHAT_ID` — ID группы заказов (например -1004415110603)

Заказы уходят на `/api/order`. Деплой нужен через GitHub (не перетаскиванием):
при перетаскивании папки функция не запускается и заказы не дойдут.

## Что легко поменять
В начале скрипта в `index.html`: контакт менеджера `MANAGER`, сумма и порог сертификата
`CERT_AMOUNT` / `CERT_MIN`, количество карточек на подгрузку `PAGE`.
Цвета тем — в начале `<style>`: блоки `html[data-theme="light"]` и `html[data-theme="dark"]`.

## Облегчённый режим стекла
На слабых Android-телефонах стекло включается в облегчённом виде автоматически:
по классу производительности, который сообщает Telegram, по объёму памяти и числу ядер.
На остальных устройствах приложение само замеряет плавность первых прокруток
и при подтормаживании переходит в лёгкий режим (запоминается на телефоне).
Проверить вручную: добавьте к адресу `?lite=1` (лёгкий) или `?lite=0` (полное стекло).

## Где хранятся данные
- Избранное, корзина, история заказов, язык, тема и данные формы — в облаке Telegram
  (CloudStorage) у самого клиента: одинаковые на телефоне, компьютере и планшете.
- Использованные сертификаты и лента «Недавно заказали» — в хранилище Netlify Blobs
  (Netlify → проект → Data & storage → Blobs, хранилище `maison-forfe`).
- Заказы с комментарием «тест» / «test» в ленту не попадают.

## Аукцион
- Лоты создаёт только владелец: Профиль → «Управление аукционом». Кнопка видна и работает
  только для Telegram ID из переменной `ADMIN_IDS` (по умолчанию 349086871).
- Цена падает каждую секунду с точностью до 1 сума: шаг в секунду считается сам из старта,
  минимума и длительности (90% времени цена снижается, последние 10% — минимальная цена).
  На экране цифры «бегут» от прошлой цены к новой.
- Время на заполнение формы после «Забрать» — 2 минуты (`HOLD_MS` в `netlify/lib/auction.mjs`).
- Лимит: 10 нажатий «Забрать» на один лот за 10 минут (`HOLD_LIMIT`, `HOLD_WINDOW_MS` там же).
- Экран аукциона: вкладки «Сейчас / Скоро», тёмная карточка лота, «смотрят сейчас»,
  цена в каталоге и скидка, полоса «старт → минимум», последние продажи.
- Покупка приходит в группу заказов с пометкой «🔨 Аукцион». Предложения цены — только во время
  торгов, приходят владельцу личным сообщением от бота.

### Пост в канале (CHANNEL_ID)
1. Бот — администратор канала с правами «Публикация» и «Редактирование сообщений».
2. Netlify → Environment variables: `CHANNEL_ID` = `@maisonforfe`.
3. Жизнь поста: за 5 минут до старта анонс с отсчётом (обновляется раз в минуту) и кнопками
   «Напомнить о старте» и «Смотреть другие позиции в каталоге» → на старте тот же пост становится
   LIVE с текущей ценой (раз в минуту) и кнопками «Перейти на аукцион», «Предложить свою цену»,
   «Каталог» → после продажи «Продан за …».
4. Название набора в посте — ссылка, открывающая каталог сразу на этом товаре.

### Ссылки на мини-апп
Кнопки в канале ведут на `https://t.me/<бот>?startapp=…`. Для этого в BotFather должно быть
включено основное мини-приложение: /mybots → бот → Bot Settings → Configure Mini App → Enable,
адрес — адрес сайта на Netlify. Если у мини-аппа есть своя ссылка вида `https://t.me/<бот>/<имя>`,
её можно указать в переменной `MINIAPP_LINK` — тогда кнопки пойдут через неё.
Параметры: `auction`, `cat`, `i_<товар>`, `remind_<лот>`, `offer_<лот>`.

### Фирменные эмодзи
Бот берёт эмодзи из пака `maisonforfe` (переменная `EMOJI_PACK`, если пак другой). В личных
сообщениях они работают при Telegram Premium у владельца бота. В канале Telegram разрешает их
только ботам с юзернеймом с Fragment — если откажет, пост уйдёт с обычными эмодзи.

### Уведомления о цене
Клиент указывает цену, и бот пишет ему, когда лот до неё дойдёт (проверка раз в минуту).
