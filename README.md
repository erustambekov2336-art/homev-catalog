# Maison Forfè — каталог в Telegram (новый дизайн)

## Что где лежит
- `public/index.html` — весь мини-апп: каталог, избранное, корзина, профиль.
- `public/uploads/homev-catalog-redesign/` — товары (`data.json`), фото, бейджи, иконки.
- `public/uploads/opt/` — сюда положить оптовые предложения:
  `maison-forfe-opt-ru.pdf` и `maison-forfe-opt-uz.pdf`. Кнопки в профиле появятся сами.
- `netlify/functions/order.mjs` — отправка заказов в группу. Токен бота хранится только в Netlify.
  Проверяет, что сертификат клиент использует один раз, и пополняет ленту «Недавно заказали».
- `netlify/functions/me.mjs` — статус сертификата клиента (одинаковый на всех устройствах).
- `netlify/functions/feed.mjs` — лента «Недавно заказали»: только набор и время, без имён.
- `netlify/lib/tg.mjs` — общая проверка, что запрос пришёл из Telegram.
- `package.json` — подключает хранилище Netlify Blobs. Netlify устанавливает его сам при сборке.
- `netlify.toml` — настройки Netlify, менять не нужно.

## Настройка в Netlify (один раз)
Site configuration → Environment variables:
- `BOT_TOKEN` — токен бота
- `ORDER_CHAT_ID` — ID группы заказов (например -1004415110603)

Заказы уходят на `/api/order`. Деплой нужен через GitHub (не перетаскиванием):
при перетаскивании папки функция не запускается и заказы не дойдут.

## Что легко поменять
В начале скрипта в `index.html`: контакт менеджера `MANAGER`, сумма и порог сертификата
`CERT_AMOUNT` / `CERT_MIN`, количество карточек на подгрузку `PAGE`.
Цвета тем — в начале `<style>`: блоки `html[data-theme="light"]` и `html[data-theme="dark"]`.

## Облегчённый режим стекла
На слабых Android-телефонах стекло включается в облегчённом виде автоматически:
по классу производительности, который сообщает Telegram, по объёму памяти и числу ядер.
На остальных устройствах приложение само замеряет плавность первых прокруток
и при подтормаживании переходит в лёгкий режим (запоминается на телефоне).
Проверить вручную: добавьте к адресу `?lite=1` (лёгкий) или `?lite=0` (полное стекло).

## Где хранятся данные
- Избранное, корзина, история заказов, язык, тема и данные формы — в облаке Telegram
  (CloudStorage) у самого клиента: одинаковые на телефоне, компьютере и планшете.
- Использованные сертификаты и лента «Недавно заказали» — в хранилище Netlify Blobs
  (Netlify → проект → Data & storage → Blobs, хранилище `maison-forfe`).
- Заказы с комментарием «тест» / «test» в ленту не попадают.
